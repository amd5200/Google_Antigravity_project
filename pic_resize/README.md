# JPG 圖片批次縮小工具 (JPG Resizer)

這是一個專為 Windows 設計的 JPG 圖片批次縮小工具，具備簡單易用的圖形介面 (GUI)，並支援多執行緒處理，讓您在縮小大量圖片時程式不會卡死。

---

## 🛠️ 功能特點

1. **圖形 UI 操作介面**：親切的繁體中文介面，操作簡單直覺。
2. **指定目標資料夾**：點擊「瀏覽...」即可輕鬆選取要處理的資料夾。
3. **儲存路徑自定義**：
   - 預設：另存至原資料夾底下的 `resized` 子目錄（保護原始圖片不被遺失）。
   - 可選：直接覆蓋原始檔案。
4. **自定義縮小百分比 (%)**：自由輸入縮小比例（範圍為 1% 到 100%）。縮小過程使用高品質 `LANCZOS` 濾鏡並會保留原始 EXIF 拍攝資訊。
5. **即時日誌與進度條**：清楚掌握目前處理的進度與檔案尺寸變化。

---

## 🚀 使用方式

### 方法 A：直接執行 `.exe` 檔案（推薦，無須安裝 Python）

1. 進入目錄 `dist/`，找到 `JPG_Resizer.exe`。
2. 雙擊執行 `JPG_Resizer.exe` 即可開啟圖形視窗。
   *(此 EXE 檔可以複製到其他 Windows 電腦上直接執行。)*

### 方法 B：透過 Python 原始碼執行

若您的電腦已安裝 Python 與必要套件，可直接執行原始碼：

1. **安裝依賴套件**：
   ```bash
   pip install pillow
   ```
2. **執行程式**：
   ```bash
   python resize_jpgs.py
   ```
